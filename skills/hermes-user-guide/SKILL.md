# 赫米斯使用者指南

## 這份文件給誰看？

**給你——赫米斯的使用者。**  
赫米斯有很多「說話方式」，這份指南讓你第一次就上手。

---

## 赫米斯的四種說話方式

| 前綴 | 意思是 |觸發什麼 | 怎麼輸入 |
|------|--------|---------|---------|
| `@` | skill 觸發 | 叫赫米斯啟動特定本領 | 直接打 `@學習` 或 `@寫作` |
| `^` | handoff 觸發 | 串接多個專家代理跑複雜任務 | 直接打 `^專案` |
| `/` | 內建指令 | 赫米斯內建功能 | 直接打 `/help` 或 `/plan` |
| （無前綴） | 一般對話 | 直接說需求 | 像LINE聊天一樣直接打字 |

---

## `@` 系列——叫出赫米斯的本領

### `@學習`（最常用）
**什麼時候用**：對話結束時，你覺得這次聊的內容值得記下來。

**你輸入**：
```
@學習
```

**赫米斯會做**：
1. 掃這次對話裡你糾正過什麼、赫米斯卡過什麼
2. 自動去重（重複的經驗不會寫兩次）
3. 把真正新的教訓寫入赫米斯的長期記憶
4. 最後告訴你「改了哪些檔」

**實際例子**：
```
你：@學習
赫米斯：@學習 觸發 → 正在掃描本次對話的試誤經驗...
         已寫入：trial-and-error/skills/hermès-internal.md（1 條新條目）
         本次修改了 1 個檔案。
```

---

### 其他 `@` 指令

| 你輸入 | 赫米斯會做 |
|--------|-----------|
| `@學習` | 把這次對話的經驗寫入赫米斯記憶 |
| `@刷新` | 顯示赫米斯系統狀態（技能數、記憶大小、最近活動）|

### `skills_list()` —— 探索赫米斯的全部本領

**赫米斯有 895+ 種本領。** `skills_list()` 是探索工具，讓你看見赫米斯會什麼。

**你輸入**：
```
你有什麼本領？
列出你的技能
你有什麼功能？
```

赫米斯會執行 `skills_list()` 並把結果整理為五大分類呈現給你：
- **系統能力** — 設定、備份、部署、監控
- **創意生成** — 圖片、影片、音樂、文字、簡報
- **資料分析** — 資料庫、爬蟲、統計、視覺化
- **自動化** — 排程、通知、跨平台同步
- **學校行政** — 公告、招聘、面試預約、文件管理

> 未來會有更多 `@` 指令，取決於你怎麼使用赫米斯。

## `^` 系列——跑大型專案

### `^專案`
**什麼時候用**：你需要「消費者調研 → 企劃 → 架構 → 工程實作 → 測試」這類多階段任務。

**你輸入**：
```
^專案
```

**赫米斯會做**：
1. 自己是 orchestrator（指揮官）
2. 串接多個專家代理分工
3. 每段代理的產出寫入硬碟、再交給下一段
4. 最後報告「每段做了什麼、產出在哪裡」

**適合**：「幫我做一個學校公告系統」、「做一個竞争对手分析報告」這類需要多種技能的大型任務。

## `/` 系列——內建功能

### 實用 `/` 指令

| 你輸入 | 赫米斯會做 |
|--------|-----------|
| `/help` | 顯示所有可用指令 |
| `/plan` | 進入規劃模式——赫米斯會問你目標、再排優先順序 |
| `/status` | 顯示目前對話的模型、session ID、對話歷史 |
| `/new` | 開新對話（清除目前對話）|
| `/title` | 幫這次對話取標題 |
| `/model` | 切換 AI 模型 |
| `/sessions` | 瀏覽或回覆之前的對話 |
| `/history` | 顯示目前對話的對話歷史 |
| `/clear` | 清除畫面、開始新對話 |
| `/save` | 儲存目前對話 |
| `/handoff` | 把目前對話交給其他平台（如從 CLI 交給 Telegram）|

**最推薦新手試的**：  
- **`/help`** —— 一覽所有指令  
- **`/plan`** —— 輸入你的目標，赫米斯幫你拆解步驟  
- **`/status`** —— 看目前 session 的詳細狀態

## 直接說話（最自然）

**不需要任何前綴。** 直接說你要什麼，赫米斯就會做。

```
範例：
「幫我查一下今天的新聞」
「把這個檔案翻成英文」
「分析這張圖片」
「幫我寫一首歌」
「這個錯誤是什麼意思？」
```

赫米斯會直接理解、執行、回覆你。

## 常見問題

**Q：輸入 `/help` 會很長嗎？**  
A：會。`/help` 顯示所有指令。**推薦先試 `/plan`**——直接輸入你的目標，赫米斯幫你想怎麼做。

**Q：`@學習` 會把整個對話都記下來嗎？**  
A：不會。赫米斯會自動去重——已經記過的經驗不會再寫。你只會得到「新增了 N 條」的報告。

**Q：我可以用中文下指令嗎？**  
A：可以。赫米斯完全支援中文輸入。

**Q：我忘記具體指令了怎麼辦？**  
A：直接問赫米斯「赫米斯有哪些指令」——赫米斯會立即給你这張前綴說明表。

**Q：輸入 `/plan` 會發生什麼事？**  
A：赫米斯會問你「目標是什麼」，你回答後，赫米斯會拆解成步驟並排優先順序。這是最有用的指令之一。
