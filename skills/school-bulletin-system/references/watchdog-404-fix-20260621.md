# School Bulletin Watchdog Bug — 2026-06-21

## 症狀

`/tmp/school-bulletin-watchdog.log` 持續報告：
```
2026-06-20 23:17:57 school-bulletin-watchdog: HTTP 404 from https://school-bulletin.vercel.app/api/health
```

但 `curl https://school-bulletin.vercel.app` 回 200，網站正常運作。

## 根因

`school-bulletin-watchdog.sh` 舊版使用 `CHECK_PATH="/api/health"`：
```bash
SCHOOL_BULLETIN_URL="https://school-bulletin.vercel.app"
CHECK_PATH="/api/health"   # ← 這個 endpoint 不存在！
```

Vercel 部署的 Next.js 應用沒有 `/api/health` route，所以永遠 404。

## 修復

將 `CHECK_PATH=""`（檢查 root URL）：
```bash
SCHOOL_BULLETIN_URL="https://school-bulletin.vercel.app"
CHECK_PATH=""   # ← 空字串，檢查 root URL
```

驗證：
```bash
$ curl -s -o /dev/null -w "%{http_code}" https://school-bulletin.vercel.app
200
```

## If→Then

**If** watchdog log 報告 `HTTP 404 from .../api/health` 但網站本身正常
**Then** 這是 `CHECK_PATH` 設為不存在 endpoint 的假性失敗，不是網站真的掛
**Then** 將 `CHECK_PATH` 改為空字串，或確認 Vercel 專案確實有該 endpoint

## 修復後部署

正確的 watchdog script 已寫入：
```
~/.hermes/skills/school-bulletin-system/scripts/school-bulletin-watchdog.sh
```

Crontab entry（每分鐘）：
```
* * * * * /tmp/school-bulletin-watchdog.sh >> /tmp/school-bulletin-watchdog.log 2>&1
```

要更新 running watchdog：複製新 script 到 `/tmp/` 並確保執行權限。
